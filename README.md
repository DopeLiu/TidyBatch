# TidyBatch 批量文件工具箱

从网盘下载一大堆文件后，往往要做些机械又繁琐的整理。这个小工具就是干这个的：
图形界面，点几下就能批量处理，**每一步都能先预览、再执行**，不会误删。

## 能做什么

| 功能 | 作用 | 例子 |
|---|---|---|
| 补充后缀 | 给没有后缀的纯数字文件补上后缀 | `12345` → `12345.zip` |
| 修改后缀 | 换掉文件的后缀 | `a.7zz` → `a.7z` |
| 清理字符 | 去掉文件名里的推广水印 | `xxx.vip@影片.mp4` → `影片.mp4` |
| 按后缀删除 | 删掉指定后缀的文件（默认进回收站） | 清理多余的 `.7z` |
| 批量压缩 | 每个文件各打成一个压缩包 | 散装文件 → 各自 `.zip` |
| 批量解压 | 批量解压压缩包 | 各自展开到同名文件夹 |

## 怎么运行

[TidyBatch.exe](dist/TidyBatch.exe) 下载即可使用

下载源码运行：电脑上需要有 **Python 3.10 或更高版本**。

```bash
python app.py               # 打开图形界面
python tests/selftest.py    # 自测一下（不会动你的真实文件）
```

不需要安装任何第三方库 —— 程序只用 Python 自带的功能。

> **小提示**：运行前先执行 `python -m tkinter`，能弹出一个测试窗口就说明环境没问题。
> 如果报错说缺少 tkinter，说明你的 Python 是精简版，用 [python.org](https://www.python.org/)
> 的官方安装包重装即可。

### 处理 .7z / .rar 格式

这两种格式需要电脑装 [7-Zip](https://www.7-zip.org/)。没装也不影响 zip 等其他格式，
只是选到 7z 时程序会提示一下。

## 怎么用

三步，很简单：

1. **选功能** —— 左侧点一下要做什么。
2. **填参数** —— 右侧填目标文件夹等，点「预览计划」。
3. **确认执行** —— 核对预览列表，没问题再点「执行」。

**为什么要分两步？** 因为「预览」只扫描、不改动，会把即将发生的每一处变化先列给你看。
核对无误再执行，能有效避免手滑。执行在后台进行，随时可以「中止」。

## 打包成 exe（可选）

想让没装 Python 的电脑也能用，可以打包成一个 exe：

```bash
pip install pyinstaller     # 只需装一次
python tools/build_exe.py   # 产物：dist/TidyBatch.exe
```

## 安全说明

改文件是有风险的，所以本工具做了这些保护：

- **先预览、后执行** —— 不确认就不会动文件。
- **删除默认进回收站** —— 文件移到同级 `.tidybatch_trash` 文件夹，可手动还原。
- **重名自动改名** —— 冲突时追加 `_1`、`_2`，绝不覆盖你已有的文件。
- **危险操作二次确认** —— 删除类按钮会变红提醒。

## 想改代码 / 加功能？

所有功能都写在 `tidybatch/operations.py` 里。照葫芦画瓢加一个类，
界面就会自动出现新入口，**不用改界面代码**。
